# Service Offer and MVP Scope (First 3 Client Engagements)

## Positioning

We deliver outcome-focused web and software projects for small businesses with fixed-scope MVPs, short timelines, and explicit acceptance criteria.

## Core Offer

- Discovery Sprint (1 week): business goals, user flow, data model, scope lock.
- MVP Build (3-5 weeks): implementation of agreed must-have features only.
- Launch + Handover (1 week): production deployment, docs, basic analytics, owner training.

## Pricing Envelope (initial)

- Engagement 1: $6k-$9k (fast website + lead capture)
- Engagement 2: $10k-$15k (service operations portal)
- Engagement 3: $14k-$22k (custom workflow automation)

Final price is fixed at scope lock; out-of-scope requests move to phase 2 backlog.

## Delivery Guardrails

- Single primary decision-maker on client side.
- Weekly demo + async status summary.
- Change requests tracked in writing and approved before implementation.
- Production handover includes source access, deployment notes, and admin runbook.

## Engagement 1: Marketing Website + Lead Intake

### Target client

Local service business with weak online conversion.

### MVP scope

- 5-8 page responsive website.
- Service catalog and conversion-focused landing page.
- Lead form with email notification + CRM/Sheet logging.
- Basic SEO setup (metadata, sitemap, search console handoff).
- Analytics events for primary calls-to-action.

### Acceptance criteria

- Mobile Lighthouse performance >= 75 on key pages.
- Form submissions are persisted and notify owner within 1 minute.
- All core pages editable by client through CMS/admin UI.

## Engagement 2: Client Intake and Job Tracking Portal

### Target client

Small team currently operating from spreadsheets and inbox threads.

### MVP scope

- Secure staff login with role-based permissions (owner/staff).
- Intake workflow: create client, create request, attach notes/files.
- Status pipeline: `new -> scheduled -> in_progress -> completed`.
- Simple dashboard for open work and overdue items.
- CSV export for weekly reporting.

### Acceptance criteria

- New intake can be created in <= 3 minutes by non-technical staff.
- Status updates are reflected across list and dashboard in <= 2 seconds.
- CSV export includes all records and required fields for accounting handoff.

## Engagement 3: Workflow Automation + Customer Notifications

### Target client

Business with repetitive manual follow-up and scheduling bottlenecks.

### MVP scope

- Rule-based task automation (trigger on intake/status/date).
- Automated email/SMS notifications for key milestones.
- Admin panel for editing notification templates and trigger rules.
- Audit log for automation actions.
- Fallback queue for failed deliveries with manual retry.

### Acceptance criteria

- At least 3 high-volume manual workflows automated end-to-end.
- Notification success rate >= 95% in first two weeks post-launch.
- Failed automations are visible with actionable retry controls.

## Non-Goals for Initial 3 Engagements

- Native mobile apps.
- Complex multi-tenant SaaS architecture.
- Deep third-party ERP integrations.
- Advanced BI/data warehouse implementation.

## Standard Phase 2 Backlog Themes

- Additional automations and integrations.
- Self-service customer account features.
- Deeper reporting and forecasting dashboards.
- Performance/security hardening beyond MVP thresholds.
